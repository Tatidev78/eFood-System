# 🍔 eFood System

A food ordering web application developed with **React**, **Redux Toolkit**, **Styled Components**, **Formik**, and **Yup**.

This project was created to practice modern Front-end development concepts, including component-based architecture, global state management, form handling, validation, and responsive user interfaces.

The application simulates a digital food platform, focusing on user interaction, organized application structure, and a smooth user experience.

# ⚙️ Installation

## Clone the repository

```bash
git clone https://github.com/Tatidev78/eFood-System.git
```

Navigate to the project folder:

```bash
cd eFood-System
```

---

## Install dependencies

```bash
npm install
```

---

## Start the development server

```bash
npm start
```

The application will be available at:

```text
http://localhost:3000
```

# 🧩 Application Architecture

The application follows a component-based React architecture:

```text
React Components
        │
        ▼
Pages and Routes
        │
        ▼
Redux Toolkit Store
        │
        ▼
Application State
```

This structure helps maintain reusable components, organized state management, and scalable development.
